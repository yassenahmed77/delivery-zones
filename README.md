# مراجعة مناطق التوصيل — Delivery Zones Review (Multi-Store Edition)

نظام متكامل لمراجعة وتأكيد مناطق التوصيل للمطاعم والمحلات التجارية — Arabic RTL · Next.js · Supabase

---

## 🌟 مميزات النظام (Multi-Store Architecture)

1. **نظام المحلات والروابط المخصصة:**
   - توليد روابط فريدة وموثقة لكل محل على حدة: `/r/[slug]`.
   - اسم المحل يظهر معتمداً ومقفولاً لمنع التداخل أو أخطاء الكتابة.
   - بيانات كل محل معزولة تماماً في قاعدة البيانات.
   - زر مباشر لمشاركة الرابط عبر الواتساب فوراً.

2. **نموذج تفاعلي فائق السلاسة (Arabic RTL):**
   - تصميم B2B حديث بألوان أنيقة وخط Cairo العربي.
   - تغطية شاملة للقاهرة والجيزة (مع تقسيم دقيق للأحياء مثل مدينة نصر، التجمع الخامس، 6 أكتوبر، الشيخ زايد...).
   - منطق تخطي تلقائي للمناطق غير المتاحة.
   - ميزة **"تحديد الكل بسعر ووقت موحد"** لتوفير وقت أصحاب المطاعم.
   - مراجعة نهائية قبل الإرسال مع إمكانية تعديل أي حي بضغطة زر.

3. **لوحة الإدارة الشاملة (`/admin`):**
   - **تبويب المحلات والروابط:** إضافة محل، توليد الروابط، نسخ الرابط، تتبع حالة الرد (✅ تم الإرسال / ⏳ في انتظار الرد).
   - **تصدير إكسل (CSV) لكل محل منفصلاً:** يدعم اللغة العربية والإكسل بدون مشاكل تشفير (UTF-8 BOM).
   - **تبويب كافة الإرسالات:** فلترة بالمحافظة، حالة التغطية، وبحث فوري في الأحياء والمناطق.

---

## 🗄️ إعداد قاعدة البيانات في Supabase

1. افتح مشروعك في **[Supabase](https://supabase.com)**.
2. اذهب إلى **SQL Editor**.
3. افتح ملف `supabase/schema.sql` من المشروع وانسخ محتواه بالكامل والصقه في الـ SQL Editor واضغط **Run**.
   - سيقوم بإنشاء جدول المحلات `stores` وجدول الإرسالات `submissions` مع كافة سياسات الحماية (RLS) والفهارس.
4. أنشئ حساب المشرف للوحة الإدارة من:
   **Authentication → Users → Add User → Create New User**.

---

## ⚙️ متغيرات البيئة (.env.local)

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_your_key_here
```

## 💻 التشغيل محلياً

```bash
# تثبيت الحزم (إن لم تكن مثبتة)
npm install

# تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على:
- النموذج العام: `http://localhost:3000`
- لوحة الإدارة: `http://localhost:3000/admin`
- رابط المحل التجريبي (بعد إنشائه من لوحة الإدارة): `http://localhost:3000/r/[slug]`

---

## 🚀 النشر على Vercel

1. ارفع المشروع إلى GitHub (تم رفعه بالفعل إلى المستودع).
2. في موقع [Vercel](https://vercel.com)، اعمل **Import** لمستودع المشروع.
3. أضف متغيرات البيئة `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`.
4. اضغط **Deploy**.
